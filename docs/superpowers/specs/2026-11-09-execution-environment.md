# Окружение процессов: минимизация передачи секретов

## Согласованная цель

Отдельный PR без масштабного рефакторинга: не передавать окружение управляющего worker целиком в Codex и команды целевого проекта. Сохранить авторизацию Codex и доверенные Git-операции. Проверить границу настоящими дочерними процессами и существующим CI. Main не изменять напрямую.

## Решение

Три профиля: project (test/lint/build/preflight target commands), codex (CLI auth/exec/resume/review), git (операции RepositoryGitService). Общий набор содержит только системные переменные для поиска программ, домашнего и временного каталогов, локали и CI. Произвольные переменные не наследуются. Дополнительные точные имена может разрешить только оператор через WORKER_PROJECT_ENV_ALLOWLIST, WORKER_CODEX_ENV_ALLOWLIST, WORKER_GIT_ENV_ALLOWLIST (через запятую, без wildcard). Worker credentials и переменные внедрения кода запрещены для такого наследования. Git auth headers формируются существующим доверенным адаптером, но передаются только сетевым Git-командам. Codex получает CODEX_HOME из AppConfig и выбранные auth-переменные; проектные команды — без них.

ShellOptions.env меняет контракт: явный env является полным окружением и НЕ дополняется process.env. При отсутствии env применяется профиль project. Все production-вызовы общего shell проверяются; Codex/Git формируют полное окружение через единый builder. Не добавляется режим широкого legacy-наследования.

## Границы

Это минимизация env, НЕ sandbox. Доступные .env/auth.json, HOME, файлы checkout, системные credential helpers, сеть, Git hooks/filters и другие процессы требуют отдельной изоляции. API-ключ Codex виден самому CLI. Параметры sandbox и политики инструментов Codex не меняются. При установке нестандартного proxy/toolchain/CA могут потребоваться явные allowlist; исключения и миграция описываются по-русски. scripts/verify-codex-cli-contract.mjs — ручная maintenance-утилита вне runtime worker, не объявляется изолированной этим PR.

## Приёмка

Фиктивный секрет родителя отсутствует у настоящих дочерних процессов shell/exec/Codex probe; явный env не объединяется с родителем; PATH и платформенные системные переменные сохраняются; профили не обмениваются credentials; Git network auth сохраняется, local git auth не получает; неверные разрешения не проходят молча; Windows case-insensitive имена не дают обхода. Backend/Angular/E2E CI зелёные. Реальные production credentials и вызовы моделей для тестов не используются.
