# Исторические планы и спецификации

Здесь хранятся рабочие планы (`plans/`) и проектные спецификации (`specs/`), созданные в ходе развития AI-Developer Worker в 2026 году.

**Важно:** это архив решений и экспериментов, а не актуальное описание поведения системы. Датированные планы могут содержать старые переменные, нереализованные задачи, временные команды, непроверенные гипотезы или ссылаться на функции, которые позже были изменены.

- [Текущая архитектура](../ARCHITECTURE.md)
- [Эксплуатационные руководства](../README.md)

## Как использовать

1. Используйте материалы для восстановления мотивов и последовательности исторических решений.
2. Для понимания **текущего** API, статусов, настройки и поведения сначала проверяйте исходный код, тесты и актуальные runbook-и.
3. Не переносите команды из старого плана в production без проверки актуальной версии.
4. Новые планы помещайте отдельными файлами с датой, не изменяя задним числом исходные исторические документы.
5. Пояснения в новых спецификациях пишите по-русски; идентификаторы, ключи и примеры кода оставляйте как в реализации.

Специализированное исследование конкурентов Wildberries/Ozon вынесено из `main` в ветку [`archive/competitor-research-2026`](https://github.com/Absens/AI-Developer-Worker/tree/archive/competitor-research-2026); исторические планы текущей ветки не являются источником этого функционала.
